Layout

Instrument, not app chrome. Screens read like calibrated panels — thin borders, mono readouts, no drop shadows.

One accent, three signals. Gold is the only decorative color. Blue/green/magenta never mean "brand" — only state.

Grid, not centering. Left-align text blocks; reserve center alignment for the runner's own 3 lanes.
